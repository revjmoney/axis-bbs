# Iniquity-style WFC, "iniquity" theme and AXIS artpack #2: Design

Date: 2026-11-04. Requested by Rev (sysop, AXIS UNDERGROUND CNC), with reference screens: an
"acid underworld" bulletin lightbar, a Copperline main menu, the "diode" menu by dky (Rev: "i really
like the diode font"), Iniquity 1.01 and 1.00 alpha 25 WFC screens ("leaning towards the iniquity wfc
style but more info"), a ViSiON/3 main menu with a rumor bar, and a WWIV node statistics window.

## Intent

Give the board the look of a mid-90s elite underground BBS from the sysop's chair and from the
caller's side. The CYD's waiting-for-caller (WFC) screen becomes an Iniquity-style console with much
more information on it, and a third theme, "iniquity", turns every caller screen green and grey,
backed by a new AXIS artpack in that style.

## Goals

1. **New WFC screen on the CYD (320x240, 40x30 text cells)**, Iniquity layout:
   - a one-line title bar ("axis micro bbs 0.3 ; (c)2026 rev j money ; node 1+2");
   - a big **AXIS** logo in the diode style (chunky blocks, blue and cyan with grey shading,
     slightly ragged edges) with "underground cnc" under it. **Logo plus that line take at most 3/16
     of the screen height (45 px, about 5 text rows)** (Rev);
   - a status line (time, date, event);
   - framed boxes: a **lightbar menu** (local logon, sysop menu, users with the waiting count, files,
     event log, setup, restart), a **nodes** box listing every node on every board (headless boards
     included, filling itself from what is online), and a **today** box with WWIV-style counters
     (calls, messages, uploads, new users, last caller) and board health (free heap, uptime, WiFi
     signal, SD free space, disc in, if the disc changer lands);
   - the status lamps (NET, LINK, SD, CALL, DOOR, PAGE) kept;
   - a footer bar in Iniquity's "(release ...) (c)" style.
   - Every menu item stays a touch button, as today's sysop menu.
2. **Fade-to-center text everywhere (Rev):** all text in the WFC and in the new theme fades from
   dark at both ends to bright in the middle. Grey to white for the WFC and the axis look; dark green
   to bright green (white on the brightest letters) for the iniquity look.
3. **"iniquity" theme**, selectable in BBS SETUP next to "axis" and "oblivion" (Rev). Every caller
   screen in that look: green and grey colours, thin frames, Iniquity-style status lines
   (`[time: 9:14pm; date: 04/02/07] [ ... ]`), the faded text, and lightbar menus.
4. **AXIS artpack #2** in the Iniquity green and grey style: big grey block lettering with green
   highlights. One screen for each of: main menu, message bases, file areas, doors, multinode/chat,
   user settings, who's online and last callers, rumors/oneliners/voting, logoff. Each title takes at
   most 3/16 of an 80x25 screen (4 rows). Delivered as `.ANS` files for the iniquity theme folder and
   packed as `AXIS-02.ZIP` in ANSI Packs.

5. **Fill out the other two themes with more ANSI (Rev).** The axis look (drippy orange) and the
   oblivion look (grey and cyan, pack #1 style) each get the same set of screens as goal 4: main menu,
   message bases, file areas, doors, multinode/chat, user settings, who's online and last callers,
   rumors/oneliners/voting, logoff. Same 3/16 title rule and fade-to-center text, each in its own
   colours. The oblivion screens go in `/sd/themes/oblivion/`, the axis ones in `/sd/themes/axis/`,
   and each set is also packed for ANSI Packs (`AXIS-03.ZIP` axis, more screens added to `AXIS-01.ZIP`
   for oblivion).

## Non-goals and anti-goals

- No art, logos or text copied from Iniquity, diode or any artpack. Same style, our own drawing.
- The WFC must stay readable at a glance from across the shop. Style must not win over legibility.
- No slower screen redraws than today, and no bigger memory use on the main (about 42 KB free).

## Constraints

- CYD screen 320x240 drawn by the firmware (`drawWfc()` in `src/main.cpp`; `BigText` 8x8 cells;
  `theme::fade` already fades per letter). Flash is tight: cyd about 96.1%, headless about 97%.
- Themes: `theme::Look { Axis, Oblivion }` in `src/bbs/theme.h`; the Oblivion look reads
  `MATRIX.ANS` / `MAIN.ANS` from `/sd/themes/oblivion/`. The iniquity look should follow the same
  pattern (its own folder), with built-in fallbacks when no art is on the card.
- Art is generated by Python tools (`tools/art/o2_style.py` makes pack #1); pack #2 gets its own
  generator in the same way.

## My calls (Claude's, Rev can overrule)

- The diode-style logo is drawn as pixels on the CYD (not text cells), so it can be fine-grained in
  45 px; the same letter shapes are reused, in blocks, for the artpack titles.
- The WFC look is the same whatever theme callers get (it is the sysop's screen).
- Theme folder: `/sd/themes/iniquity/` with the same file names the oblivion look uses, plus one per
  menu.

## Left to the builder

- Exact box sizes and colours inside the stated layout; which counters fit.
- How the fade is computed for very short labels.
- The artpack generator's internals.
